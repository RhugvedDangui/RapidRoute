RapidRoute V1 - Setup Guide
============================

STEP 1: API Keys (All FREE - No Credit Card!)
----------------------------------------------

1. OpenRouteService (for routing)
   - Go to: https://openrouteservice.org/dev/#/signup
   - Sign up with email only
   - Copy API key
   - Add to .env: OPENROUTE_API_KEY=your_key_here
   - Free tier: 2000 requests/day

2. TomTom Traffic API (for real-time traffic in India!)
   - Go to: https://developer.tomtom.com/user/register
   - Sign up with email only
   - Create an app
   - Copy API key
   - Add to .env: TOMTOM_API_KEY=your_key_here
   - Free tier: 2500 requests/day
   - ✅ Best India coverage (Mumbai, Delhi, Bangalore, Hyderabad, Chennai, Pune)

STEP 2: Install Dependencies
-----------------------------
pip install -r ../requirements.txt

STEP 3: Generate Training Data
-------------------------------
cd V1
python ml/generate_training_data.py

This creates 10,000 realistic delivery records with:
- Distance, courier scores
- Weather (rain, wind, temperature)
- Traffic patterns (peak hours, weekends)
- Delay probabilities

STEP 4: Train XGBoost Model
----------------------------
python ml/train_model.py

Expected performance:
- Accuracy: ~87%
- Precision: ~84%
- Recall: ~82%
- Training time: ~2 minutes

STEP 5: Start API Server
-------------------------
python main.py

Server runs at: http://localhost:8000
API docs: http://localhost:8000/docs

STEP 6: Test the API
---------------------
python test_api.py

Or use the interactive docs at /docs

API REQUEST EXAMPLE
-------------------
POST /api/v1/predict-delay

{
  "order_id": "ORD-123",
  "origin_lat": 12.9716,
  "origin_lon": 77.5946,
  "dest_lat": 12.9352,
  "dest_lon": 77.6245,
  "courier_reliability_score": 0.85,
  "time_of_day": 18,
  "is_weekend": false
}

RESPONSE INCLUDES
-----------------
- risk_score: 0.0-1.0
- risk_level: "low" | "medium" | "high"
- explanation: Plain English reason
- suggested_action: What to do
- weather_data: Live from Open-Meteo
- traffic_data: Live from TomTom
  - current_speed_kmh: Real-time speed
  - free_flow_speed_kmh: Normal speed
  - traffic_level: 0-100 (higher = worse)
  - delay_factor: 1.0 = normal, 2.0 = double time
  - confidence: 0-1 (data quality)

TROUBLESHOOTING
---------------
Model not loading?
  → python ml/train_model.py

Training data missing?
  → python ml/generate_training_data.py

OpenRouteService error?
  → Check API key in .env
  → Free tier: 2000 requests/day

Port in use?
  → PORT=8001 python main.py
